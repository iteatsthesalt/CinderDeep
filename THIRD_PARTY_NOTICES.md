# Third-party notices

CinderDeep organizes upstream projects using Git submodules at exact commits. It does not replace or alter the original license files, copyright notices, attribution, or project histories. Initialize the submodules to obtain those files alongside their original sources.

There is no single license covering the entire collection. No new license is asserted for third-party content or for the linked gist. GitHub API license labels are retained only as metadata; they are not a substitute for each project's license and notices.
